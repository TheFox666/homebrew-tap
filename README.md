# homebrew-tap

Homebrew formulae for [mduct](https://github.com/TheFox666/mduct).

```sh
brew install thefox666/tap/mduct
```

`brew upgrade` picks up new releases. The formula installs the release binary
for your platform and verifies its checksum; nothing is built locally.

Formulae here are generated from the mduct repo (`bun run formula`) on each
release — send changes there, not here.
